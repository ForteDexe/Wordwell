Wordwell privacy policy

Effective date: October 30, 2026

Wordwell checks grammar and translates text using a model running on your device. Wordwell does not send your writing, translations, model files, or diagnostics to the developer or an inference service. There are no accounts, advertising, analytics, or telemetry in the extension.

Text processing

With automatic checking enabled, Wordwell reads text in the supported text box you are editing after a typing pause. Automatic checking is on by default and can be turned off in Settings. Manual correction and translation process the text you select or enter when you request a check. Page selection translation and text-box translation are separate options, both off by default. Password inputs and disabled fields are excluded.

Text, prompts, proposed corrections, translations, and sentence caches are processed in memory on your device. They are not saved as a writing history. Text sent through the context menu is temporarily held in Chrome's session storage until the workspace receives it, or until the browser session ends. Replacements require your action; optional Instant translation replaces the selected editable text after you click its translation icon.

Models and saved settings

When you load a GGUF file, Wordwell saves one unchanged copy in the extension's local IndexedDB storage so it can autoload without asking for the file again. The saved metadata includes the file name, size, and save time. Selecting and loading a different model replaces that saved copy. This uses disk space approximately equal to the model file's size.

Chrome's local extension storage holds settings such as languages, context size, automatic checking, translation options, a custom prompt if you save one, and the autoload preference. Wordwell does not use Chrome storage sync to send these settings to another device.

Diagnostics and clipboard

Editor diagnostics are generated only when you request them. The last five reports are kept in Chrome's session storage. Reports include the site's hostname, editor tags, IDs, classes and roles, sizes, selection lengths, extension state, and error metadata. They exclude the text you are writing and password values. Reports are not uploaded automatically. If you choose to copy and share a report for support, it is shared by your own action.

Copy buttons write the requested correction, translation, or diagnostics to your clipboard. Wordwell does not read your clipboard. Local engine logs and the current workspace text remain in memory until cleared, replaced, or the workspace is closed.

External links

The optional model download link opens Hugging Face. The support and source links open GitHub. Those sites receive the ordinary browser requests made when you open them and have their own privacy policies. Wordwell does not attach your writing or diagnostics to these links. Grammar checking and translation work offline once a model has been downloaded and loaded. Chrome's own extension installation and update services are separate from Wordwell's text processing.

Your controls and retention

  • Turn off Automatic checking or either translation option in Settings to stop that feature.
  • Use Clear text to clear the workspace text and result. Closing the workspace releases its text, engine, and in-memory caches.
  • Use Clear reports to remove saved editor diagnostics. Session storage is also cleared when the browser session ends.
  • Use Forget model to delete the saved model and disable autoload. An engine already in memory stays loaded until you use Unload or close its workspace.
  • Saved settings and the cached model persist across browser starts until changed or removed. Uninstalling the extension removes its extension storage; it does not remove the original model file you downloaded or text already copied to your clipboard.

Permissions

  • Access to HTTP and HTTPS pages lets Wordwell show correction underlines and selection tools in supported fields and frames.
  • Storage remembers preferences and session state.
  • Unlimited storage supports the large local model copy without ordinary extension storage quota restrictions.
  • Context menus provide selection checking and editor diagnostics.
  • Clipboard write enables the explicit Copy buttons.

Wordwell uses user data only for its correction, translation, and requested diagnostic features, consistently with the Chrome Web Store User Data Policy and Limited Use requirements. It does not sell user data, share it for advertising, or transfer it to the developer.

Contact and changes

Wordwell is maintained by ForteDexe. For privacy questions, use the Wordwell issue tracker. Issue reports are public, so share only information you want to publish.

Changes to data handling will be reflected in this policy and the extension's disclosures. The effective date above identifies this version of the policy.
